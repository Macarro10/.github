# Como contribuir (padrão da conta)

Este arquivo é o padrão de Macarro10 para repositórios que ainda não têm um `CONTRIBUTING.md` próprio. Repositórios com guia próprio usam o arquivo local.

## Antes de abrir uma mudança

1. Leia o README do repositório e, se existir, o `SUPPORT.md` e o `SECURITY.md`.
2. Prefira mudanças pequenas, com mensagem de commit clara.
3. Não abra issue pública com segredos, tokens, `.env`, chaves, dados pessoais ou detalhes sensíveis de verificação.

## Pull requests

- Descreva o que mudou e por quê.
- Se o repositório tiver testes ou gates, diga o que rodou e o resultado.
- Não altere visibilidade de repositório nem remova arquivos sem alinhamento explícito com o mantenedor.

## Segurança

Relatos de vulnerabilidade: use a política de segurança do repositório (aba Security → Policy) ou o `SECURITY.md` padrão da conta. Não use issues públicas para isso.
