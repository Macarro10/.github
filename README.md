# Defaults de saúde da comunidade — Macarro10

Repositório público especial (`.github`) com arquivos padrão da conta. O GitHub usa estes arquivos em qualquer repositório de Macarro10 que ainda não tenha o mesmo arquivo próprio. Documentação: [Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

## Arquivos neste repositório

- [`SECURITY.md`](SECURITY.md) — política de segurança padrão (como reportar vulnerabilidades)
- [`SUPPORT.md`](SUPPORT.md) — onde pedir ajuda (padrão da conta)
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — como contribuir (padrão da conta)
- [`.github/pull_request_template.md`](.github/pull_request_template.md) — template padrão de pull request
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) — chooser de issues (contact links + templates de dúvida e de problema/bug)

## Notas

- Este repositório precisa permanecer **público** para os defaults funcionarem.
- Não altere a visibilidade sem aprovação explícita.
- Repositórios com `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md` ou templates próprios continuam usando o arquivo local.
