# Política de segurança (padrão da conta)

Este arquivo é o padrão de Macarro10 para repositórios que ainda não têm um `SECURITY.md` próprio. Repositórios com política própria (por exemplo [Macarro10/Macarro10](https://github.com/Macarro10/Macarro10/blob/main/SECURITY.md)) usam a deles.

## Como reportar

Para reportar uma vulnerabilidade em qualquer repositório de Macarro10, use "Report a vulnerability" (Security → Advisories) no repositório afetado, se disponível, ou entre em contato pelo GitHub ([@Macarro10](https://github.com/Macarro10)). Não abra issue pública com detalhes.

Inclua, quando souber:

- repositório, commit, tag ou SHA afetado
- descrição do problema e por que é sensível
- passos para reproduzir
- impacto potencial e mitigação sugerida, se houver

Não anexe nem cole segredos, tokens, `.env`, chaves ou dados pessoais.
