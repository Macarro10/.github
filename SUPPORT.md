# Suporte (padrão da conta)

Este arquivo é o padrão de Macarro10 para repositórios que ainda não têm um `SUPPORT.md` próprio.

## Onde pedir ajuda

- Dúvidas gerais: contato pelo GitHub ([@Macarro10](https://github.com/Macarro10)).
- Relatos de segurança: use a política de segurança do repositório (aba Security → Policy) ou a [política no perfil](https://github.com/Macarro10/Macarro10/blob/main/SECURITY.md). Não abra issue pública com detalhes sensíveis.

## Documentação

Quando o repositório tiver README, CONTRIBUTING ou SECURITY próprios, prefira esses arquivos locais.
